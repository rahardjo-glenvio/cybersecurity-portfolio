# Tools 🔧

Kumpulan tool keamanan siber yang ada di repository ini. Setiap folder memiliki README sendiri untuk detail instalasi dan penggunaan.

## Ringkasan

| Folder | Deskripsi singkat |
| --- | --- |
| `HeimdallrOsint` | OSINT & exposure monitor untuk domain, fokus pada temuan kebocoran publik. |
| `ReconForge` | Framework recon otomatis (passive + active) dengan output laporan. |
| `network` | Utilitas jaringan untuk reconnaissance, termasuk port scanner sederhana. |
| `WazuhSIEMxSentinelMap` | Folder dokumentasi/placeholder untuk mapping Wazuh SIEM x Microsoft Sentinel. |

## Struktur

```
tools/
├── HeimdallrOsint/
├── ReconForge/
├── WazuhSIEMxSentinelMap/
└── network/
```
